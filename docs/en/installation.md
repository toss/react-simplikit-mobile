# Installation

## Core Package

```bash
# npm
npm install react-simplikit

# yarn
yarn add react-simplikit

# pnpm
pnpm add react-simplikit
```

## Mobile Package

```bash
# npm
npm install @react-simplikit/mobile

# yarn
yarn add @react-simplikit/mobile

# pnpm
pnpm add @react-simplikit/mobile
```

## Requirements

- React 18 or higher
- TypeScript 5.0 or higher (recommended)

## Usage

```tsx
// Core package
import { useBooleanState, useDebounce } from 'react-simplikit';

// Mobile package
import { useAvoidKeyboard, useScrollDirection } from '@react-simplikit/mobile';
```
